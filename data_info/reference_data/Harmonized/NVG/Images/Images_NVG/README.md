# NVG examples

This folder contains the figures used to illustrate the NVG reference dataset and the analyses performed during its processing and harmonization.

The examples show, in general terms:

* spatial configuration of pixel-level vegetation-change detections within NVG sub-parcels;
* comparison of the temporal distributions of `Data0` and `Data1`;
* identification of temporally homogeneous and heterogeneous sub-parcels;
* assessment of dominant-date patterns and temporal dispersion using metrics such as P90–P10 and Q3–Q1;
* comparison between CCDC results and the visually interpreted timing of vegetation-change events;
* evaluation of possible sub-parcel separation based on distinct spatial and temporal patterns;
* use of Sentinel-2 imagery and interactive inspection tools for validation.

The complete interpretation, processing workflow, and figure descriptions are provided in:

`Harmonized/NVG/NVG.md`
