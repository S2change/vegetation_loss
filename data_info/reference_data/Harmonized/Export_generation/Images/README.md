# Export Generation examples

This folder contains the figures used to illustrate the harmonized data export workflow executed in QGIS.

The examples show, in general terms:

* selection of one or more harmonized reference sources;
* temporal filtering by year and month;
* selection of shared and source-specific output fields;
* combination of filtered BDR, BDR Expanded, NVG, and ICNF features into a single output layer;
* confirmation of the GeoPackage export and automatic loading of the result in QGIS;
* application of source-and-date labels and monthly temporal symbology.

The complete workflow, interpretation, and figure descriptions are provided in:

`Harmonized/Export_generation/Export_data_generation.md`
