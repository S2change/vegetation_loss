# BDR-TNE-300-Expanded examples

This folder contains the figures used to illustrate the BDR-TNE-300-Expanded reference dataset.

The examples show, in general terms:

- expert discrimination between land-cover classes;
- identification of burned areas using several image sources;
- comparison between CCDC dates and visually interpreted change timing;
- use of Sentinel-2 imagery, orthophotos, and Google Earth for validation.

The complete interpretation and figure descriptions are provided in:

`Harmonized/BDR_and_BDR_expanded/BDR_expanded.md`
