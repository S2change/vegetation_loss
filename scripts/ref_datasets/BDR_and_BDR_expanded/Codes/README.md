# BDR and BDR Expanded Processing Codes

This folder contains the Python code used to process and harmonize the BDR and BDR Expanded reference datasets.

The code is organized into:

* `core/`: shared spatial-processing functions;
* `pipelines/`: main processing and harmonization workflows;
* `runners/`: executable scripts used to run each workflow;
* `utils/`: supporting utilities, including text normalization.

BDR and BDR Expanded use separate runners but share the main harmonization pipeline.
