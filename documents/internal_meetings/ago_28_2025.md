
#### sara: using Google 64 band product to test capability to detect changes

Input:
1. ano: um valor entre 2018, 2019, 2020 ou 2021
2. dados referência DGT 300 (casos positivos para esse ano) e dados antónio (não alteração)
3. imagem (64 bandas) Google
4. N=número de pontos a extrair

Output:
tabela com N linhas  em que cada linha é um pixel, com 64 colunas das variáveis do Google para cada pixel, x, y, e um "label" 1 se o pixel teve perda de vegetação no ano e 0 caso não tenha alteração, codigo do polígono (dados de referência).
